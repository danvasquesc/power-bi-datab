# Power BI - DATAB

Repositório criado para armazenar e organizar materiais de estudo do curso de Power BI da DATAB.

## Conteúdo

- Vídeos das aulas;
- Exercícios e materiais de apoio;
- Links relacionados a outro curso indicado no youtube;
- Arquivos utilizados durante os estudos.

## Git LFS

Os vídeos possuem arquivos de grande tamanho e são armazenados utilizando **Git LFS (Large File Storage)**.

Os arquivos `.ts` da pasta `videos_datab` são gerenciados pelo Git LFS através do arquivo `.gitattributes`.

## Estrutura

- `videos_datab/` - Vídeos das aulas;
- `.gitattributes` - Configuração do Git LFS;
- `link_hashtag_treinamentos` - Link relacionado ao curso no youtube;

## Objetivo

Manter os materiais do curso organizados e disponíveis para estudo e consulta em diferentes máquinas.
